# Local interface font

Cantarell variable font copied from the forge's abattis-cantarell-vf-fonts
system package, 2026-10-18. Copyright attribution and SIL Open Font License
are retained verbatim in OFL.txt. Upstream: https://cantarell.gnome.org/ .
Bundled as the Kumbia font family so the game starts without a Google Fonts
network request. This is a UI font; character/environment art remains pixel art.
