# Input silhouettes

Project-authored SVG paths, 64×64 viewBox, transparent background, no fonts or embedded bitmap. Tint to the cue palette at render time. `left_hand` = upper left; `right_hand` = upper right; `left_foot` = lower left; `right_foot` = lower right. These name Mācron's logical moves, not the player's physical input limb. Runtime touch regions fill their quadrants; SVG bounds never define touch targets. Keep the icons shape-identical in previews, judgment markers and accessibility layouts. Icons rest faintly; active required cues require adequate contrast.
