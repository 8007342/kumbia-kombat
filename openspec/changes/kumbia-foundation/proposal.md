# Kumbia Kombat foundation

Replace the generic landing-page product definition with five portrait,
one-handed rhythm dance fights driven by original adaptive synth music.
Create original score data, audio transport and combat foundations, art
starters, acceptance specifications and a session-by-session production plan.

This change starts implementation; it does not claim the complete campaign,
production synth backend, global service or finished animation are shipped.
The existing landing remains until the vertical slice passes its gates.

Validation: score generator validation; pure Dart musical transport and
combat tests; Flutter analyze/test; release web build where available.
Work branch: work/1824-kumb → PR to game → PR to main. No production deploy
is part of this foundation change.
